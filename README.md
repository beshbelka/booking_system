# КИНОЗАЛ — Система бронирования билетов

О ПРОЕКТЕ
---------
Данный проект представляет собой веб-приложение для имитации работы
кинотеатра. Разработан в качестве учебного пет-проекта для отработки
навыков веб-разработки (Backend + Frontend) и работы с базами данных.

ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ
---------------------------

1.  АВТОРИЗАЦИЯ И АУТЕНТИФИКАЦИЯ
    - Регистрация нового пользователя.
    - Вход в систему по email и паролю.
    - Разграничение прав доступа: Пользователь (USER) и Администратор (ADMIN).

    *Тестовые учетные записи для входа:*
    
| Роль   | Логин                | Пароль   |
|--------|----------------------|----------|
| **USER**  | user@email.com       | password |
| **ADMIN** | admin@email.com      | password |

2.  ВОЗМОЖНОСТИ ПОЛЬЗОВАТЕЛЯ (USER)

    - Управление профилем: создание, редактирование личных данных,
      удаление аккаунта.
    - Просмотр списка доступных фильмов и сеансов.
    - Создание бронирования на определенный сеанс.
    - Отмена (аннулирование) существующего бронирования.
    - Просмотр истории своих покупок/броней.

3.  АДМИНИСТРАТИВНАЯ ПАНЕЛЬ (ADMIN) (доступна только для роли ADMIN)
    Полный функционал пользователя (кроме создания и удаления аккаунта) + расширенные возможности:
    - Управление фильмами.
    - Управление сеансами.
    - Управление пользователями.
    - Управление бронями.
    - Финансовый модуль.
    - Общая информация о системе.

ТЕХНОЛОГИЧЕСКИЙ СТЕК
------------------------------------

- Backend: Java, Spring Boot
- База данных: PostgreSQL + In-memory
- Frontend: Thymeleaf, HTML + CSS
- Сборка: Maven
- Безопасность: Spring Security, JWT

ЗАПУСК ПРОЕКТА (инструкция)
---------------------------
1. Склонируйте репозиторий
   
2. Создайте базу данных

3. Запустите приложение

4. Откройте браузер и перейдите по адресу:
   http://localhost:8080
